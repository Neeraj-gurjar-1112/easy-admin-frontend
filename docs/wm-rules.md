# WM rules used in this repo (with the Notion sources)

Fetch the page when in doubt — do not guess.

| Topic | Rule in one line | WM page |
|---|---|---|
| Class names | lowercase-with-hyphens (`main-container`) | [WM \| HTML development guideline](https://app.notion.com/p/9695262a68b7463db0d750634029da96) |
| Colour variables | colour + code (`$red-b1`), never a meaning (`$red-dark`) | same |
| Icons | `icon-<name>-<colour>`; check it does not exist already | same |
| Breakpoints | 1920 → 1600 → 1366 → 1280 → 1024 → 991 → 768 → 640 → 480 → 375 | same |
| Buttons / images | width from padding, images fit their box | same |
| Comments | comment almost every block in HTML / JS / style | same |
| Light / dark | every [day] colour has exactly one [night] colour with the same name; mode-independent colours go in a Constant group | [WM I Light/Dark Mode Color System](https://app.notion.com/p/75711652f115489c9d0800aa76c44da4) |
| Date format | Korean `YYYY년 M월 D일` (no leading zero); English `May 1, 2016` or `YYYY-MM-DD`; 오전/오후 before the time, AM/PM after | [WM \| Development - Date format Manual](https://app.notion.com/p/c9e5a7fdd2f541a1a6bf127e3e92cc27) |
| Numbers | comma every three digits, always; KRW has no decimals (`9,900원`) | [WM \| Three digit coma rule](https://app.notion.com/p/3ba0ef434e254bb4a20d10cb17f57655) |
| Error messages | use the shared list for validation / API errors | [WM \| Error Message List](https://app.notion.com/p/f0a07346bd2349e28bc76abe2fe135ac) |
| Password format | HW2 forms, if a password field exists | [WM \| Password Format](https://app.notion.com/p/6b6da9b04c134821b0d7d5e2ee3ad7d3) |
| Design review | checklist before coding (container size, spacing, components, font, line breaks, empty/no-image states, button width, image fit, browser support) | [WM \| Design guidelines for designers](https://app.notion.com/p/3d66aa4c0ef1487c87abd45f16f280cb) · [WM \| Figma Setting Rules](https://app.notion.com/p/2fdb2ebedc3742ba9ea38a9cd8ddc40e) |
| QA | test-case template, QA process, build sharing | [WM \| QA Template](https://app.notion.com/p/89e8efe5cbf746a29882ae011be5446e) · [WM \| Work Manual for QA Process](https://app.notion.com/p/bab0d0977e6c4c48943c1c6476dd6e95) · [WM \| Build sharing plan](https://app.notion.com/p/cb95b97f449e417995c449e08aba4f1f) |
| Reports | build report format | [WM \| Report](https://app.notion.com/p/09990cac269f41ccabd31deb069512bf) |
